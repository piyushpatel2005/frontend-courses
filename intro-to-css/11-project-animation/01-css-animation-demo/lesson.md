# Kite festival signal demo

**Mission:** Add gentle motion to the Kite Festival signal without making it distracting.

This finished mini-build shows **transitions and keyframe animation** in context. In `style.css`, find the declarations that shape the preview and connect each selector to the element it changes.

## Try the demo

Change one visible value in `style.css` (such as a color, gap, or size), select **Run Preview**, and observe exactly what moves or changes. Restore the original value before continuing so the completed example remains your reference.
