# Exercise: Flex Direction

## Mission

Flex direction decides whether a trail-kit list grows across or down.

## Your Tasks

1. Turn `.kit-row` into a flex container.
2. Set its direction to `row`.

## Checkpoint

Run the preview. The layout should remain easy to scan before you submit the tests.

## Payoff

You have turned one layout intention into clear, reusable CSS.
