# Exercise: Flexbox Navigation

## Mission

Finish a compact expedition header: a title on one side and actions on the other.

## Your Tasks

1. Make `.nav-row` a flex container.
2. Place the cards at opposite ends with `justify-content: space-between`.
3. Center the cards vertically with `align-items: center`.

## Checkpoint

Run the preview. The layout should remain easy to scan before you submit the tests.

## Payoff

You have turned one layout intention into clear, reusable CSS.
