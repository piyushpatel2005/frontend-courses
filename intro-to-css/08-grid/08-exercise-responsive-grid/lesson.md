# Exercise: Responsive Grid

## Mission

The workshop board must look spacious on a wide screen and readable on a phone.

## Your Tasks

1. Make `.responsive-grid` a three-column grid.
2. Add a media query at `max-width: 36rem` that changes it to one column.

## Checkpoint

Run the preview. The layout should remain easy to scan before you submit the tests.

## Payoff

You have turned one layout intention into clear, reusable CSS.
