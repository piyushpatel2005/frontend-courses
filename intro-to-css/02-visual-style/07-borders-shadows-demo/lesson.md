# Borders and Shadows Demo

## Mission

The night-market vendor cards need clear edges and enough depth to stand apart from the page.

## What to notice

Borders define an edge; border radius softens it; a box shadow gives an element visual elevation.

## Try the preview

Change one visible value in `style.css`, run the preview, and observe the difference. Restore the original value before the exercise so this completed page remains your reference.

## Checkpoint

You can point to the selector, property, and value responsible for the visual change.

## Learn more

MDN’s official documentation explains shadow offsets, blur, spread, inset shadows, and multiple shadows. Read [MDN’s reference for the `box-shadow` CSS property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/box-shadow) when you want to go further.
