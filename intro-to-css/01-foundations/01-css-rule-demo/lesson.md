# CSS Rule Demo: Style an Exhibit Card

## Mission

The Tideglass Museum has published a plain exhibit card. The completed example applies two small CSS rules so you can see the difference CSS makes to existing HTML.

## What you'll see

A museum card with a pale background and blue heading.

## Read the code

```html
body { background-color: #f6f8fb; }
h1 { color: #1b4d8c; }
```

## Try the preview

Run the completed page. Then, just for exploration, change the `h1` color in `style.css` from `#1b4d8c` to any color you choose, run again, and restore the original color before continuing.

## Checkpoint

Identify the selector, property, and value that created the visible change. Nothing needs editing in this demo.
