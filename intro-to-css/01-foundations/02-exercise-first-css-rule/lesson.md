# Exercise: Write Your First CSS Rule

## Mission

The exhibit card is plain again. Add the same kind of CSS rules you just observed in the demo.

## What you'll build

A pale page background and a blue exhibit heading.

## Your Tasks

1. Keep the existing link to `style.css`; write the CSS rules in that file.
2. Add `background-color: #f6f8fb;` to a `body` rule.
3. Add `color: #1b4d8c;` to an `h1` rule.

## Checkpoint

Run the page. The background should become pale and the heading blue.

## Payoff

You have written a selector, property, and value—the basic unit of CSS.
