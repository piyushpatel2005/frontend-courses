# Exercise: Make a Fluid Weather Bulletin

## Mission

Make the weather bulletin adapt naturally between narrow and wide screens.

## Your Tasks

1. Set `.page-shell` `width` with `min(92%, 48rem)`.
2. Use `repeat(auto-fit, minmax(14rem, 1fr))` for `.bulletin` grid columns.
3. Set `.card` padding with `clamp(1rem, 3vw, 2rem)`.

## Checkpoint

Use fluid sizing functions and an auto-fit grid before reaching for another media query.

## Payoff

You now have another focused CSS tool for making interfaces easier to use.
