The preceding program showed two different ways to continue a sequence. The starter has the context; add one numbered section and one lettered section.

## Your Tasks

1. Add an `<ol start="4">` with two non-empty `<li>` event steps, continuing from 4.
2. Add another `<ol type="A" start="3">` with two non-empty `<li>` activities, continuing from C.

Run to see 4, 5 and C, D. `start` takes the position number even for alphabetic markers. Submit to check both lists.
