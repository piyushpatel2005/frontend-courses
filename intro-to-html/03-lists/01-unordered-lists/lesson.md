The garden table needs three supplies, but no one has to pack them in a particular order. Run the completed page and look for bullets.

An unordered list uses `<ul>` around its `<li>` items. The list element holds the group; each item is its own child. Choose this shape when sequence would imply a rule that does not exist.

## Check the preview
