A garden volunteer needs explanations, not steps or supplies. Run the glossary to see each term followed by its meaning.

A `<dl>` groups descriptions. A `<dt>` names a term, and its following `<dd>` gives its description. Unlike `<ul>` and `<ol>`, a description list does not use `<li>`. Keep each explanation directly after the term it describes.
