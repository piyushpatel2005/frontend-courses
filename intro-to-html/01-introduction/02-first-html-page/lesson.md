The survey team has reached a new landing site. Write an arrival signal for the bridge using the heading and paragraph tags you just saw in the previous lesson. Choose new words rather than copying the demo's transmission.

The starter already contains the document setup. Edit `index.html` between `<body>` and `</body>`. Each paragraph needs its own opening `<p>` and closing `</p>`. You can also use the code from previous lesson for reference. There is also a way to check hints and finally, you have an option to check the full solution by clicking on *Solution*.

## Your Tasks

1. Add exactly one `<h1>` that includes **Meridian** or **Signal**.
2. Add a non-empty `<p>` with an arrival details, something like "Approaching Dock station 101".
3. Add a second non-empty `<p>` with the team's next step ("Let's get ready for next mission").

## Check your page

Press **Run** to see a heading followed by two paragraphs. Press **Submit** to check each task. If text disappears or runs into the wrong element, compare your opening and closing tags.
