# Exercise: Build a Complete HTML5 Page

## Mission

You have inspected a complete mission profile. Now turn the provided starter into your own version, keeping the page structure that makes it reliable and understandable to browsers.

## What you'll build

A complete HTML5 mission profile with a meaningful tab title, an English language declaration, visible profile content, and a source-only note.

## Your Tasks

1. Give the existing `<title>` element a meaningful, non-empty title.
2. Keep `<!DOCTYPE html>` as the first line of the document.
3. Keep `lang="en"` on the `<html>` root element.
4. Add exactly one `<h1>` inside `<body>` with a crew member's name.
5. Add one `<p>` inside `<body>` describing the crew member.
6. Add an HTML comment above the `<h1>`.

## Checkpoint

Run the page. The tab should show your title, while the preview should show only the heading and paragraph. Open the source to confirm that the comment is present but not visible in the page.

## Payoff

You have rebuilt the full structure behind a browser-ready HTML page. The next module expands the content you can place inside its body.
