# List Types Demo: Steps, Items, and Terms

## Mission

The Meridian crew prepares for a night rescue. The loadout needs launch steps, loose gear, and short definitions for two mission systems.

## What you'll see

A completed loadout using an ordered list, unordered list, and description list.

## Read the code

```html
<ol><li>Check the beacon.</li><li>Charge the wrist light.</li></ol>
<ul><li>First-aid pouch</li><li>Signal flares</li></ul>
<dl><dt>Beacon sight</dt><dd>Locates a nearby distress signal.</dd></dl>
```

Use `<ol>` for a sequence, `<ul>` when order does not matter, and `<dl>` for terms and definitions.

## Try the preview

Run the page. The launch sequence is numbered, the rescue kit is bulleted, and each mission system term stays paired with its explanation.

## Checkpoint

Use the preview to connect each visible result to the HTML that created it. For a safe experiment, change the `<ol>` to `<ul>`, rerun to see the numbering turn into bullets, then restore it.
