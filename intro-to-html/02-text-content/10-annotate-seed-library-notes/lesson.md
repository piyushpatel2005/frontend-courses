The previous page showed how a sentence and a standalone note use different quotation elements. A community seed library needs the same pattern for its pickup instructions. The starter has a heading and one paragraph; keep them and add one piece at a time.

## Your Tasks

1. In the existing paragraph, mark the volunteer's words with `<q>`; keep the quote inside that paragraph.
2. Add a separate `<blockquote>` with a non-empty `<p>` explaining how to return seeds.
3. In a paragraph, expand the abbreviation `FAQ` with an `<abbr title="Frequently asked questions">` element.
4. In a paragraph, mark a short terminal command as `<code>`.

Run after each change. The short quote belongs in the existing sentence, while the longer note gets its own block. Submit when all four relationships are in place. The glossary and command can use your own surrounding words.
