The library has one menu for requests. Following the community hall walkthrough, put the four existing options into two labeled groups. The supplied label still names the whole menu; a group label explains only its own choices.

## Your Tasks

1. Inside the existing select, add an `<optgroup label="Loans">` containing the Borrow and Renew options in that order.
2. Add a second `<optgroup label="Events">` containing the Book club and Reading class options in that order.
3. Keep the select's `id="request"`, `name="request"`, connected visible label, and the four original non-empty option values; leave no options loose outside the groups.

Run and open the menu. You should find two non-selectable group names and the same four selectable choices. Submit when the labels and values still match.
